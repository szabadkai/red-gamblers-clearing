# Woodland flora provenance

`woodland-flora.png` contains six original pixel sprites created for this game:
two ivory lily clusters, two red mushroom clusters and two teal mushroom clusters.
They were authored as pixel shapes and palettes, without sampling the reference
image or third-party artwork. Created 2026-11-21.

Editable source and regeneration instructions are retained at
`sources/woodland-flora/` in the source repository. The game uses a transparent
192×24 atlas, six 32×24 cells, at 2× scale. These additions do not change the
licenses of other assets or grant a blanket asset-reuse license.
