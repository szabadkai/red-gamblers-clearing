# Reusable prototype assets

`web/` retains sprites, backgrounds, audio, concept art and animation definitions
from the former web game. `godot/` retains reusable scenes and the original icon;
scene texture references point to the root `Assets/` collection.

These are reference and authoring resources, not a second runnable game. The
previous complete prototypes remain in Git history. The active browser game
and its static release live in `../poker-web/`.

[the asset inventory](../docs/ASSET_INVENTORY.md) and
[asset rights](../ASSET_RIGHTS.md).
