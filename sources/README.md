# Editable sources

The playable exports live in `../poker-web/assets/`. Keep source material here
so artwork and music can be rebuilt without shipping authoring files to players.

| Directory | Contents |
| --- | --- |
| `lrrh_sprites/` | Aseprite projects, Lua generators, sprite sheets and art review evidence |
| `chiptune/` | Music scores, render tools and rendered tracks |
| `bridge/` | Stone bridge tile and arch generator |
| `terrain/` | Stage foundations, detail tiles and autotile generators |
| `woodland-flora/` | Lily and mushroom atlas generator and provenance |
| `generated-images/` | Original generated scenery and art references |

Original purchased packs remain in `../Assets/` with their author notices.
See [the asset inventory](../docs/ASSET_INVENTORY.md) and
[asset rights](../ASSET_RIGHTS.md) before reusing any artwork.
