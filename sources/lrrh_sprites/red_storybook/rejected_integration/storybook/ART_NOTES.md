# Storybook Red

`red.png` is the runtime atlas derived from the user-supplied Huntsman's Bridge
character reference using OpenAI image generation. The original reference,
generated sheet, prompts, and reproducible Pillow packing script are retained in
`sources/lrrh_sprites/red_storybook/`.

The atlas has 128 frames in an 8 × 16 grid with 64 × 64 pixel cells and a common
anatomical pivot at (32, 54). Frames are rendered at 2× with nearest-neighbor sampling.
The renderer recolors scarlet cloth to plum for the powered Dark Red form.

Select Settings → Red’s appearance → Storybook Red, or open `?skin=storybook`
for a preview that does not overwrite the stored appearance preference.
All movement, attacks, damage, and hitboxes retain their original rules.

This generated alternative is separate from the purchased sprite packs. The
reference was supplied by the user; its rights were not independently established.
No additional rights to the reference or blanket asset license are asserted.

Movement and combat were revised with dedicated source sheets, preserved in the
source directory with their prompts. The active mapping uses separate horizontal,
rising and overhead sword attacks, a horizontal dash, distinct rise/fall poses,
landing squash, look-around and a two-stage cloak transformation.
